# Algo Journey

My journey on learning algorithms through LeetCode challenges.

## Overview

This repository documents my progress solving LeetCode problems. Each solution includes:
- **Filename** — The problem/quiz name
- **Solution** — Implementation of the solution
- **Thoughts** — Reasoning and approach of the solution in the code comments

## Structure

```
algo-journey/
├── category-name/         # e.g., arrays, strings, dynamic-programming
│   ├── problem-name.js    # Each quiz inside its category folder
│   └── ...
└── README.md
```

Problems are organized by **category folders**, with each quiz file placed inside its corresponding category.
